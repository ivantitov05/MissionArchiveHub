# Sorcerer Mission Archive

**Веб-сервис для централизованного хранения, обработки и анализа миссий магов**

---

## 📋 О проекте

Система представляет собой расширяемый анализатор миссий, поддерживающий загрузку файлов в форматах JSON, XML, TXT, YAML. Данные нормализуются в единую внутреннюю модель, сохраняются в базу данных PostgreSQL и доступны для последующего просмотра и генерации аналитических отчётов.

### Ключевые возможности

- **Многопользовательский режим** — загрузка и просмотр миссий через веб-интерфейс
- **Гибкая система парсинга** — автоматическое определение формата файла
- **Архивное хранение** — PostgreSQL для долговременного хранения
- **Генерация отчётов** — краткая сводка, детальный отчёт, анализ рисков
- **REST API** — полная документация через Swagger/OpenAPI
